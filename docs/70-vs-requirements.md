# 70. Готовый функционал vs требования (v5, ревизия)

Итоговый срез реализации v5 (чисто ЛС-модель): что работает, как выглядит
интерфейс, какая логика под капотом — и сопоставление с требованиями из всей
истории обсуждений.

## 1. Функционал (готовое)

| Область | Что работает |
|---|---|
| Подписка | Без кнопок: любой пишущий проверяется по `groups.isMember` — не член → «🔒 Нет доступа»; член → авто-подписка и сразу **все** активные карточки; академ (исключён) → «📴» и ничего не приходит |
| События | `/событие Название - 15.09 19:00 - 15.09 21:00 - описание` → превью → `[🚀 Опубликовать]/[🗑 Отмена]` → живые карточки в ЛС (VK-подписчики + слинкованные TG) |
| RSVP | Кнопки `[✅ Приду] [🤔 Возможно] [❌ Не приду] [🗑 Снять ответ]`; смена выбора — зачёркивание с временем (юникод в VK / `<s>` в TG + fallback-флаг); дедуп по person |
| Текстовое голосование | Reply на карточку: «пойду/+/да» → да; «возможно/может» → может; «не пойду/-/нет» → нет; «снять» → снять; опрос — «2» или «1,3» или «снять» |
| Опросы | `/опрос Вопрос` + варианты построчно, `[несколько]`, `[до 20.09 19:00]` (старый формат через `;` тоже работает); тумблеры вариантов (в ЛС на кнопках виден свой выбор ✅); одиночный/мультивыбор; «(снял выбор, 19:40)»; авто-закрытие по сроку; итоги |
| Управление | `/edit <id> <поля как при создании>` (+ алиас `/изменить`); `/удалить <id>` (карточки удаляются у всех); **закрыть и снова открыть запись/опрос** (`[🔒]`⇄`[🔓]` в панели, авто-закрытие срабатывает один раз); компактные списки `[📋 События]/[📋 Опросы]` с `[⚙️ #id]` → панель `[📢 Объявление] [✏️ Изменить] [🔒/🔓] [❌ Отменить] [📊 Итоги] [🗑 Удалить]` (+ `[✅ Кто пришёл]` у закрытых событий) |
| Посещаемость | `[✅ Кто пришёл]` / `/посещаемость <id>` — отметка реально пришедших (кнопками), попадает в экспорт |
| Экспорт | `/экспорт` — красивый xlsx (листы «События» с именами и посещаемостью, «Опросы» с вариантами) файлом в ЛС |
| Лог в сообщество | Завершённые события, закрытые опросы и объявления публикуются постом на стене сообщества (`VK_WALL_LOG=true`) |
| Тех-уведомления | `TECH_ADMIN_VK_PEER` — «✅ Бот запущен» и суточный heartbeat (время, подписки) в чат «Логи» |
| Объявления | Глобальное (`[📢 Объявление]` → диалог) и по событию/опросу (из панели): секция «📢 Объявления» в карточке + TTL-уведомления (48 ч) с медиа-вложениями; схлопывание (edit того же уведомления) |
| Изменения | `/edit` → перерисовка всех карточек + уведомление «⚠️ Изменение #id …» (как объявление) |
| Членство/админы | Админы = руководители сообщества (`groups.getMembers filter=managers`, раз в сутки) + `ADMIN_VK_IDS`; guard `require_admin` на всех админ-кнопках; блокировка — пассивная пометка при 900/901 |
| Режимы админа | `[🔁 Режим админа]` ↔ `[🔁 Режим участника]` (+ `/admin`, `/member`); режим хранится в БД, переживает рестарт |
| TG | Карточки/уведомления/кнопки в ЛС слинкованным; алерт без линковки («1) напиши боту ВК… 2) укажи ник TG»); настройка `[🔕 Уведомления]`; линковка только со стороны ВК (ник TG в настройках), смена @username связь не рвёт |
| Обращения | `[📩 Написать админам]` — релей сообщений руководителям в VK ЛС (VK и TG) |
| Напоминания | За 24 ч и 2 ч — reply'ем на карточку (события — от начала, опросы — от closes_at) |
| Жизненный цикл | Авто-закрытие записи (at_start/before_start), авто-завершение (+5 мин) с финальной сводкой, авто-закрытие опросов, отмена |
| Надёжность | Outbox (send/edit/delete, ретраи, рейт-лимиты, одно pending-задание на пост); сверка карточек (тик 30 с, батчи); UNIQUE-индексы против дублей; TTL-очистка уведомлений; дедуп двойных нажатий (2 с) |

## 2. CJM

### 2.1 Участник VK
```
Пишет боту → isMember (кэш 10 мин)
  ├─ не член → «🔒 Нет доступа: бот только для участников сообщества клуба»
  ├─ академ → «📴 Ты в академе…» (ничего не приходит)
  └─ член → авто-подписка + карточки всех активных событий/опросов + меню
Карточка события: кнопки или reply-текст → тост «Записал ✅» → карточка живёт у всех
Уведомления: объявления (по настройке), изменения, закрытие/отмена, напоминания
Настройки: объявления вкл/выкл · ник TG · отписка (/стоп) · «❓ Как голосовать»
[📩 Написать админам] → сообщение уходит руководителям; ответ админа (reply) —
  обратно в чат (можно несколько раз)
Академ: админ исключает из сообщества → синк ставит paused + «📴»; вернулся → «👋»
```

### 2.2 Участник TG
```
/start → статус привязки («✅ привязан: Аня К.» / «не привязан»)
Привязка — только из ВК: настройки → «Мой ник в TG» → авто-линковка по @username
  → сразу все активные карточки в TG ЛС
Голос кнопкой: слинкован → засчитан (имя из ВК); не слинкован → алерт с инструкцией
Уведомления в ЛС (можно выключить) · [📩 Написать админам]
```

### 2.3 Админ (VK ЛС)
```
Админ автоматически (руководитель сообщества) или через ADMIN_VK_IDS
Режимы переключаются кнопкой — клавиатура меняется
Создание: /событие … или /создать опрос … → превью → публикация
[📋 События]/[📋 Опросы] → компактный список (#id, сроки, ✅🤔❌, 👀 охват) → [⚙️ #id] → панель
Правка: /edit <id> … — из любого места чата; участники получают «⚠️ Изменение»
Объявление: глобальное кнопкой; по контенту — из панели (секция в карточке + уведомления)
[❓ Помощь] — полная справка; /подписчики, /связать vk tg
```

## 3. Команды (полный список)

| Команда | Действие |
|---|---|
| `/start` | Меню с клавиатурой по состоянию |
| `/стоп` | Отписка от событий |
| `/событие Название - начало - конец - описание` | Создать событие (превью) |
| `/опрос Вопрос` + варианты построчно, `[несколько]`, `[до …]` | Создать опрос (превью) |
| `/edit <id> <поля как при создании>` / `/изменить` | Изменить событие/опрос |
| `/удалить <id>` | Полное удаление (карточки удаляются у всех) |
| `/посещаемость <id>` | Отметка «кто реально пришёл» |
| `/экспорт` | xlsx с итогами файлом в ЛС |
| `/help` | Справка админа |
| `/события` | Список активных событий |
| `/подписчики` | Статистика подписок |
| `/связать <vk_id> <tg_id>` | Ручная линковка |
| `/admin` / `/member` | Переключение режима админа |
| reply-текст на карточке | Голос текстом («пойду», «2», «1,3», «снять»…) |

## 4. Интерфейсы (клавиатуры)

### VK ЛС
- **Не член**: без клавиатуры — «🔒 Нет доступа» (академ — «📴 Ты в академе…»)
- **Участник**: `[📅 События] [🗳 Голосования] / [⚙️ Настройки] [📩 Написать админам]` (+`[🔁 Режим админа]` у главы в режиме участника)
- **Админ**: `[➕ Событие] [➕ Опрос] [📢 Объявление] / [📋 События] [📋 Опросы] [👥 Подписчики] / [🔗 Связать аккаунты] [🔄 Синхронизация] / [🔁 Режим участника] [❓ Помощь]`
- **Карточка события**: `[✅ Приду] [🤔 Возможно] / [❌ Не приду] [🗑 Снять ответ]`
- **Карточка опроса**: `[✅ 1 Парк] [2 Кино] … / [🗑 Снять выборы]`
- **Настройки**: `[Объявления: вкл/выкл] [✏️ Ник TG] [🔕 Отписка] [❓ Как голосовать] [⬅️]`
- **Списки админа**: строки + `[⚙️ #id]`; панель: `[📢 Объявление] [✏️ Изменить] / [🔒 Закрыть] [❌ Отменить] [📊 Итоги]`

### TG ЛС
- Не слинкован: `[📩 Написать админам]`
- Слинкован: `[📅 События] [🗳 Голосования] [⚙️ Настройки] [📩 Написать админам]`
- Настройки: `[🔕 Уведомления: вкл/выкл]`

## 5. Логика (ключевые механизмы)

- **Outbox**: единственный путь исходящих; задания send/edit/delete с
  idempotency_key, ретраями (5, экспонента), рейт-лимитами (VK ~3/с глобально,
  ≤1/с на пир; TG ≤25/с, ≤1/с на чат); одно pending-задание на пост — свежая
  версия обновляет VM на месте.
- **Карточка в единственном экземпляре**: на (контент, подписчик) ровно один
  пост dm_card (UNIQUE-индекс); обновления — `messages.edit` на месте (live
  проверено: текст и клавиатура заменяются); удалённую пользователем карточку
  пересоздаём новым send.
- **Очистка уведомлений**: dm_notice живут 48 ч и удаляются `messages.delete`
  (live проверено: deleted=1); повторные изменения редактируют то же уведомление.
- **Сквозной id**: `contents` — единая нумерация событий/опросов; `#id` первой
  строкой карточки; reply резолвится по тексту.
- **Имена из ВК**: у слинкованной персоны показывается имя ВК-аккаунта;
  TG-голос без линковки не принимается (алерт).
- **Сверка**: каждые 30 с батчами — карточки всех подписчиков существуют и
  актуальны (потерянные пересоздаются, дубли исключены индексами).
- **Таймеры**: напоминания (reply на карточку), авто-закрытие, авто-финиш,
  авто-закрытие опросов, **синк админов/членства раз в час** (+ кнопка
  `[🔄 Синхронизация]` с отчётом), TTL-очистка.
- **Дедуп нажатий**: окно 2 с по (user, action, id, value) — защита тумблеров
  от двойного клика.

## 6. Сравнение с требованиями

| Требование (из обсуждений) | Статус | Где |
|---|---|---|
| Объявления через ВК-бота, в т.ч. с медиа | ✅ (+медиа доделано в ревизии) | announcements + senders |
| Создание событий админом | ✅ | /событие |
| Дополнительные объявления по событиям | ✅ | панель [⚙️] → секция + уведомления |
| Для члена клуба всё выглядит как переписка с ботом | ✅ | карточки/уведомления в ЛС |
| Ответ «пойду/не пойду» | ✅ | кнопки + текст |
| Более широкие голосования | ✅ | опросы (до 10 вариантов, мультивыбор, срок) |
| Ник TG указывается в ВК (только так) | ✅ | настройки → линковка |
| Алрет в TG, если не указан ВК, с описанием ошибки | ✅ | callback-алерт |
| Имена при записях — из ВК | ✅ | display_for |
| Объявления и в TG, и в VK | ✅ | notice_dm_tracked (VK + TG) |
| Сообщения о событии/опросе меняются в каждом чате при голосе | ✅ | refresh_content → edit всех карточек |
| Переключение режимов админа, клавиатура меняется | ✅ | accounts.mode + send_menu |
| Использовать reply и inline кнопки | ✅ | reply-меню + inline-карточки/панели |
| TG — общение с ботом, не в группе | ✅ (v5) | только ЛС |
| id в каждом посте сверху, уникальный | ✅ | contents + `#id` |
| /edit <id> … | ✅ | + алиас /изменить |
| Кнопка подробной помощи админу | ✅ | ❓ Помощь (+ справка участника) |
| Списки событий/опросов в чате с кнопками управления | ✅ | [📋] + [⚙️ #id] (ссылки убраны вместе со стеной — отменено пользователем) |
| Валидация членства = нахождение в сообществе | ✅ (вместо заявок) | groups.isMember |
| Сообщество — только админы и членство | ✅ (v5) | group_managers + isMember |
| Единственная карточка + очистка уведомлений | ✅ (live проверено) | dm_card edit / dm_notice delete |
| Сверка «всё на месте и актуально» + дедуп | ✅ | jobs reconcile |
| Напоминания reply'ом | ✅ | notice_dm_reply_cards |
| Обращения к админам | ✅ | релей в VK ЛС; ответ админа reply'ем на пересланное сообщение уходит участнику (многократно) |
| Стена ВК / TG-канал / мост / беседа | ➖ отменены пользователем | — |

## 7. Ограничения и известные мелочи

1. Медиа в **секции** карточки — текстом (само вложение — в TTL-уведомлении);
   видео — ссылкой. Полный цикл «фото в объявлении» не прогнан live.
2. Диалоги (объявление, ник, обращения) держатся в памяти — рестарт сбрасывает
   незавершённый ввод.
3. Дедуп нажатий — в памяти, окно 2 с.
4. Блокировка бота участником — только пассивная пометка (900/901); чёрный
   список админ ведёт сам в ВК.
5. Обращения — релей без хранения истории; ответ админа — reply'ем.
6. БД пересоздаётся (alembic не заведён); старые данные не мигрируются.
7. TG-часть не прогнана live целиком (карточки/уведомления) — сетевой доступ к
   api.telegram.org есть только с VPN; бот и канал-логика проверены getMe/getChat.

  обращения, посещаемость; аналитика: списки, статистика, экспорт xlsx.
