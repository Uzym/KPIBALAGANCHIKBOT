## 1. Оплата (ежемесячный взнос)

- Конфиг: `FEE_MONTHLY_RUB=200` (ежемесячный взнос), `DEBT_ALERT_LIMIT_RUB=600`
  (порог оповещения админов о долге).
- Модель: одна таблица `fee_entries` (person_id, kind: `accrual|payment`,
  amount_rub со знаком: начисление +, платёж −, month для accruals,
  label «за что», created_at). Долг человека = сумма записей.
- Начисления: автоматически 1-го числа каждого месяца всем active-подпискам
  (VK и TG); новому участнику — при активации подписки за текущий месяц
  (если ещё не начислено). В академе/паузе — начисления пропускаются,
  долг сохраняется.
- Команды:
  - участник: `/оплата` (или кнопка «💰 Оплата») — «Твой долг: N ₽»
    + последние начисления/платежи;
  - админ: `/оплата <кто> <сумма> <за что>` — фиксация платежа;
    отрицательная сумма = корректировка долга;
  - админ: `/долги` — список должников (долг > 0), ⚠️ у кого > порога;
  - админ: `/история <кто>` — начисления/платежи человека.
- Оповещение о долге: при пересечении порога (600) — сообщение админам
  (один раз; флаг `fee_alerted` на персоне сбрасывается, когда долг упал
  ниже порога).
- Экспорт: лист «Оплата» в `/экспорт` (долги всех).
- «Кто» в командах — vk_id, tg_id или имя (поиск по override/имени).

## 2. TG полностью отдельно

- Флоу первого старта TG-бота:
  - привязан к члену VK (линковка) → как раньше;
  - не привязан → бот: «Заявка отправлена руководителям»; админам в ВК —
    сообщение с inline-кнопками `[✅ Пустить] [❌ Отказать]` (имя, @username);
  - ✅ — создаётся Person (имя из TG), Subscription `active`, все активные
    карточки в ЛС, человеку «Добро пожаловать!»;
  - ❌ — Subscription `blocked` + пометка `banned`; человеку «Заявка
    отклонена»; повторный `/start` не спамит заявками (одна активная заявка).
- Баны: `/бан <кто>` / `/разбан <кто>` (админ) — блокирует все действия
  человека (голоса не принимаются, карточки не шлются). VK-баны (900/901) —
  как раньше.
- Членство для «чистых» TG: не проверяется через VK; доступ = approved-
  подписка. Оплата работает и для TG-участников.

## 3. Чаты только для чтения + беседа с карточками

- Конфиг: `READONLY_CHAT_PEERS` (список, напр. `2000000007`),
  `CARD_CHAT_PEER=2000000008`.
- Read-only чат: любое сообщение от людей (включая админов) удаляется
  (`messages.delete`, `delete_for_all=1`; бот должен быть **админом** чата),
  нарушителю в ЛС — «Здесь писать нельзя» + inline-кнопка `[Я понял]`
  (callback) → нажатие удаляет и это сообщение.
- Карточки событий/опросов публикуются **одной общей карточкой** в беседу
  «Инфо» (вместо персональных ЛС-карточек VK). В ЛС у людей остаются:
  оповещения, настройки, оплата, обращения.
- Переработка кнопок под общую карточку (кнопки «неизменяемы» для каждого
  в отдельности — клавиатура общая на всех):
  - события: `[✅ Пойду (3)] [🤔 (1)] [❌ (2)]` — счётчики в подписях;
    после каждого голоса карточка перерисовывается (`messages.edit` по
    conversation_message_id), свой выбор виден только в снекбаре;
  - опросы: на кнопках вариантов счётчики голосов (без персональных ✅);
    мультивыбор — повторное нажатие снимает;
  - объявления: секция в общей карточке + оповещения в ЛС (как было).
- TG-карточки остаются персональными в ЛС (у TG нет общего чата).
